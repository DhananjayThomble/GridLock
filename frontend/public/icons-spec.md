# PWA Icons Spec

Provide the following files in `frontend/public/`:

- `icon-192.png` (192x192 px)
- `icon-512.png` (512x512 px)

Guidance:
- Use GridLock branding with a clear, centered symbol.
- Keep strong contrast for visibility on home screens.
- Prefer solid background using app palette:
  - `#0F172A` base
  - `#3B82F6` and `#8B5CF6` accents
- Avoid small text inside icons.
