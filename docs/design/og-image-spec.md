# OG Image Spec

Create `og-image.png` at `frontend/public/og-image.png`.

Required size:
- 1200x630 px

Guidance:
- Include GridLock branding and game context (Dots & Boxes board motif).
- Match the app visual identity:
  - Background: `#0F172A`
  - Primary blue: `#3B82F6`
  - Accent purple gradient tones
- Keep title text readable at social preview sizes.
